# SideNeko full signing and installation implementation

This directory incorporates and modifies source code from
[SideInstaller by FrizzleM](https://github.com/FrizzleM/SideInstaller).

- Upstream snapshot supplied by the user on 2026-11-19.
- Upstream version shown in its README: 2.1.0.
- SideNeko changes the application identity, bundle identifiers, URL scheme,
  icons, orange visual theme, project names and product wording.
- The signing, Apple Account, anisette, certificate, pairing, tunnel and
  installation implementation originates from SideInstaller.
- SideNeko remains free, non-commercial and source-available.
